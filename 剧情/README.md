# 剧情目录

本目录是游戏剧情的唯一归档入口。按“卷 → 章 → 内容类型”组织；每一章的可执行数据、可读正文、策划资料及版本备份必须一同维护。

## 当前结构

```text
剧情/
└─ 第一卷_黑雨/
   └─ 第一章_黑雨/
      ├─ 内容包/  # 运行时读取的 JSON：节点、任务、人物、材料、遭遇、山海志与世界状态
      ├─ 正文/    # 供审稿、配音与演出使用的可读小说稿
      ├─ 资料/    # 接入说明、扩写蓝图、结构研究等
      └─ 备份/    # 按日期和内容版本冻结的完整章备份
```

## 维护规则

- 新章节必须在本目录新建 `第X卷_名称/第Y章_名称`，不得将剧情正文散落到代码或临时目录。
- 内容包的稳定 ID 不因移动、润色或版本备份而改变。
- 每次章节内容发生实质修改后，在该章 `备份/` 下建立一个 `YYYY-MM-DD_v版本号` 快照；备份内容包含 `内容包`、`正文` 与 `资料`。
- 构建脚本 `tools/build_black_rain.py` 已从本目录读取第一章内容包，并重新生成 `正文/黑雨_完整游戏小说.md`。
