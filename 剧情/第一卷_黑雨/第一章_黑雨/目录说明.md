# 第一卷《黑雨》·第一章

## 本章文件

- `内容包/`：游戏直接加载的数据源。修改后运行 `python tools/build_black_rain.py` 校验引用并更新可读小说稿。
- `正文/`：完整游戏小说母稿与文学扩写版；前者由构建脚本生成，后者用于叙事、配音与演出审读。
- `资料/`：十小时章节扩展蓝图、扩写执行计划、文本结构研究、接口接入说明。
- `备份/`：每次冻结的完整章节快照。目录名使用 `YYYY-MM-DD_v内容版本`。

当前 `v3.0.0` 包含 365 个可达节点、31 条任务、12 个遭遇、32 条山海志与 28 件材料/工具；生成的全节点小说母稿为 110,295 汉字。内容覆盖三座中型副本、人物与地点回访、材料显形、北滩谈判、四条主结局及其后日回访，并新增黑雨七日记、六件普通事、未送达回执与雨后初课四组可回访剧情。十小时完整探索仍以 `资料/10小时章节扩展蓝图.md` 和新档试玩记录为验收基线，不以节点数或全文字数直接等同于时长。
