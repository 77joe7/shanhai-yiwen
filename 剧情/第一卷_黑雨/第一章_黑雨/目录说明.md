# 第一卷《黑雨》·第一章

## 本章文件

- `内容包/`：游戏直接加载的数据源。修改后运行 `python tools/build_black_rain.py` 校验引用并更新可读小说稿。
- `正文/`：完整游戏小说母稿与文学扩写版；前者由构建脚本生成，后者用于叙事、配音与演出审读。
- `资料/`：十小时章节扩展蓝图、扩写执行计划、文本结构研究、接口接入说明。
- `备份/`：每次冻结的完整章节快照。目录名使用 `YYYY-MM-DD_v内容版本`。

当前 `v4.0.0` 包含 463 个可达节点、31 条任务、12 个遭遇、32 条山海志与 28 件材料/工具；生成的全节点小说母稿为 99,934 汉字。第一、二幕已替换为分支剧情系统（`app/game/branching/acts.ts`）：每节点选项严格 ≤3 且带 `no` 编号，第一幕三去向（记历棚/渡口/粮仓）→ 幕终「承诺身份」→ 第二幕三入口 → 北滩三后果轴（羿箭/迟日/含晦）→ 三卷终分别桥接第三幕；第三四五幕超限节点按「无损拆分」扩展为分组入口（42 节点 → 147 个中间节点），不删除任何已批准分支。内容覆盖三座中型副本、人物与地点回访、材料显形、北滩谈判、四条主结局及其后日回访，并保留黑雨七日记、六件普通事、未送达回执与雨后初课四组可回访剧情。十小时完整探索仍以 `资料/10小时章节扩展蓝图.md` 和新档试玩记录为验收基线，不以节点数或全文字数直接等同于时长。
