# 第一卷《黑雨》扩写执行计划 v1.3

- 状态：主生产批次完成，待新档试玩验收
- 对应内容版本：`CONTENT-V01-BLACK-RAIN v3.0.0`
- 目标：将当前“可运行的章节雏形”扩充为主线首通约 3—4 小时、全探索目标约 10 小时的单机文字角色扮演章节。
- 依据：`10小时章节扩展蓝图.md`、`接入说明.md`、V1.3 游戏说明书摘录与当前内容包。

## 1. 当前基线与完成口径

本轮扩写完成后，内容包有 365 个可达 StoryNode、31 条任务、12 个遭遇、32 条山海志、28 件材料/工具、11 名主要角色。可读小说母稿为 110,295 汉字。

这些数据说明第一卷已经具备完整开场、主线闭环、三处副本入口、四种主结局与部分回访，但不代表已经达到十小时。节点数和字数只能作为生产量指标；实际时长必须以新档试玩记录验证。

本计划采用三个时长口径：

| 口径 | 目标 | 说明 |
| --- | ---: | --- |
| 最短主线 | 3—4 小时 | 玩家只走必要线索与一条低代价解法；不要求收集、刷取或重复试错。 |
| 完整首周目 | 7—8 小时 | 完成三座副本、六条核心人物线、关键材料显形和一次结局。 |
| 全探索 | 9—11 小时 | 完成可回访事件、材料洞彻、山海志核心层、人物余响，并查看四条主结局的差异入口；不把读档重刷计算为主时长。 |

## 2. 文本与节点产能目标

本轮已达成 11 万汉字内容预算下限；继续验收时不以“把每个节点写长”为唯一手段，而以长场景、调查链、空间谜题、人物争执和雨后回访共同构成有效阅读与决策时间。

| 指标 | 当前 | 章节验收目标 | 增量策略 |
| --- | ---: | ---: | --- |
| 可读母稿汉字 | 23,841 | 110,000—140,000 | 每座副本增加 2.0—3.0 万字；人物线与回访增加 4.0—5.5 万字。 |
| 全部作者文本（含互斥分支） | 约 30,000 | 180,000—220,000 | 使用状态汇合，避免为四个结局复制整章。 |
| StoryNode | 98 | 150—165 | 新增 52—67 个高密度节点；旧节点可改写、拆分，但稳定 ID 不复用。 |
| 每个有效节点 | 当前不均 | 叙事节点 800—1,500 字；短遭遇 350—700 字 | 关键场景必须有观察、冲突、选择与后果，避免纯说明段。 |
| 微型遭遇 | 4 | 12 | 每个 5—10 分钟，至少提供两种处理方法和一个世界/人物后果。 |
| 材料/工具 | 12 | 28—32 | 每件进入“获得—显形—使用—代价/余响”至少三段链条。 |

> 字数是内容预算，不是时长承诺。每完成一个批次必须以新档试玩、节点路径记录和阅读节奏复盘更新估算。

## 3. 扩写总原则

### 3.1 剧情结构

每个新增事件必须回答一个问题、让一个人暴露立场、改变一项可读状态，并提供至少一个可追溯的后果。

```mermaid
flowchart LR
    A[异常或人物请求] --> B[观察与对话冲突]
    B --> C[调查/材料/关系选择]
    C --> D[战斗、谈判、仪式、潜行或撤退]
    D --> E[获得证据或支付代价]
    E --> F[状态写入]
    F --> G[新入口、角色态度、图鉴层或卷末余响]
```

禁止用以下方式虚增时长：重复跑图、同义反复对白、无意义收集、失败即重开、只有数值不同但故事相同的选项。

### 3.2 对话与人物

新增对白必须继续使用中文引号“”。每个核心人物在一个场景中应至少完成其中两项：提出具体需求、反驳他人、隐瞒事实、用行动暴露恐惧、要求玩家承担条件。

角色不应替设定讲解。设定须通过争执、物件、账本、伤口、食物、路径和人物的具体利益出现。

### 3.3 数据与接口

- 新节点进入 `story-nodes-expansion.json`；成熟后可按批次合并基础文件，但运行时始终加载两者。
- 新增 ID 一律使用 `V01-C01-N100` 以后、`Q-V01-SIDE-014` 以后、`EN-V01-*`、`IT-V01-*`、`CX-V01-*` 的稳定命名空间。
- 每个新增任务至少有 `objectives`、`failure`、`relatedNpcIds`、`relatedItemIds`；失败只能转换为时间、资源、关系、地点或证据代价。
- 每个新增关键选择至少写入一个 `setFlag`、`setWorldVar`、`changeRelation`、物品、图鉴或任务状态，并在后续节点或 `V01-C01-N028` 看到回响。
- 每个新材料须写入 `items.json`，按认知层显示；不得用临时展示名替换实体 ID。
- 每批结束运行 `python tools/build_black_rain.py`、`pnpm run test`、`pnpm run lint`，并建立章节备份。

## 4. 批次 A：倒船腹舱深化

### 目标

将“归还者号”从当前可进入的三门场景，扩充为本卷第一个完整中型副本。玩家在此判断宿沙之子是走私者、替罪者还是被利用的证人，但不能获得一个无代价的唯一答案。

### 内容预算

| 项目 | 目标 |
| --- | ---: |
| 新节点 | 12—14 |
| 新文本 | 22,000—28,000 汉字 |
| 新任务 | 1 条：`Q-V01-SIDE-014` 或将现有“归还者的三响”升级为阶段任务 |
| 新遭遇 | 2 个：水客记忆、船底报债人 |
| 新材料/证据 | 4 件 |
| 首次游玩增量 | 35—45 分钟 |

### 节点链

1. **入舱复核**：把昨日水位门、货单门、三响门的线索放到同一张“船行图”上；不足线索可进入，但会承担误认代价。
2. **逆潮廊道**：船舱每开一门，场景退回一刻钟；玩家可追人、守证、或固定时间。
3. **水客记忆遭遇**：错误记忆凝成水客，解决方式为裂陶哨听空、囚雨芦引流、与宿沙核对渡工信号、强行驱散。
4. **儿童名牌舱**：发现“梦税”借渡记录；选择救一份即将被洗去的名册或保全整箱证据。
5. **船底缝**：与旧盐井暗渠建立物理连接；可提前解锁井下捷径，也可封住防止黑雨扩大。
6. **宿沙对质**：宿沙承认自己知道运的不是普通盐，却不知道孩子名单；玩家不能替他宣判，只能决定证据的保管与公开程序。
7. **返航结算**：船退回河床或留作证据，影响季狸、黎苇和旧井暗渠的后续条件。

### 新材料链

| 实体 | 获得 | 显形 | 使用与代价 |
| --- | --- | --- | --- |
| 返潮绳结 | 逆潮廊道 | 确认可固定一段“回去的路” | 旧井撤退时用；会牺牲一条暗渠线。 |
| 梦税名牌 | 儿童名牌舱 | 确认其记录被当作货运凭记 | 用于公开指控或送还家属；二者不可兼得。 |
| 水客牙 | 驱散水客 | 确认会咬住叙述中的漏洞 | 谈判时识破伪证；使用后降低宿沙信任。 |
| 旧船蜡印 | 货单门 | 与季狸真印比对 | 解锁北方文书质询；公开会暴露黎苇路线。 |

### 验收

- 入口至结算不低于 30 分钟；至少三条完成路线。
- 宿沙、青芽、黎苇至少各有一次互相反驳，不以玩家独白代替冲突。
- 至少三项选择在旧井或终局被读取。

## 5. 批次 B：东桑十巢深化

### 目标

把东桑林从路径谜题扩充为阿禾的完整人物副本：她坚持给物命名，玩家则必须面对“保住道路”和“保护眼前村人”无法同时满足的代价。

### 内容预算

| 项目 | 目标 |
| --- | ---: |
| 新节点 | 10—12 |
| 新文本 | 18,000—24,000 汉字 |
| 新任务 | 1 条阿禾阶段任务 |
| 新遭遇 | 2 个：无名树回送、鸟影叼走名字 |
| 新材料/工具 | 4 件 |
| 首次游玩增量 | 30—40 分钟 |

### 节点链

1. **命名簿**：阿禾拿出羊群、老人和桑树的旧名，玩家决定按旧名、临时名或不命名探索。
2. **无名树回送**：每次走错返回入口，但会带回一个陌生人的短暂记忆；可用扶桑烬、羊铃、人物细节破解。
3. **鸟影借名**：鸟影偷走撤离名单上的名字，玩家在“追鸟救名”和“护巢稳路”中取舍。
4. **第十巢梦壳**：梦壳展示一个没有弱者的“高效撤离”；阿禾与黎苇就谁被删去发生对立。
5. **东行门**：三影者出现，提出要一条通往扶桑的路；玩家可保密、命名或烧毁路标。
6. **雨后桑林回访**：根据选择显示新树名、空巢数量、阿禾对小满及村人的态度。

### 验收

- 阿禾至少有一次明确反对玩家的选择，且不因好感数值自动让步。
- 扶桑烬、滞影泥、受雨空巢至少各有一次非战斗用途。
- 东桑路线至少影响“东行/迟日/撤村”三个卷末状态之一。

## 6. 批次 C：旧盐井深层与含晦收束

### 目标

旧盐井是第一卷的核心副本。它必须承担历史真相、个人罪责、材料显形、战斗/仪式多解与撤退代价，而不是只作为通往含晦的一条走廊。

### 内容预算

| 项目 | 目标 |
| --- | ---: |
| 新节点 | 14—16 |
| 新文本 | 28,000—35,000 汉字 |
| 新任务 | 1 条缄婆/砚伯共线，1 条砚童梦税线 |
| 新遭遇 | 2 个：盐层人话、失名童工 |
| 新材料/工具 | 6 件 |
| 首次游玩增量 | 45—60 分钟 |

### 节点链

1. **井口准备扩充**：药、绳、留守、证词保管四项不能全部满足；每种准备提供不同撤退或对话选项。
2. **采盐层**：寻找昼盐采掘痕；看见成人与孩子交替留下的凿痕。
3. **人话盐层**：被封的第一句求救会模仿亲近的人；玩家可听、记录、用材料封存或拒绝。
4. **梦税名单室**：砚童的梦、旧账与河运名牌被合并为可验证证据链。
5. **暗渠坍塌/捷径**：倒船腹舱的选择决定此处是救援通路还是污染来源。
6. **昼盐池前证词审问**：砚伯、缄婆、宿沙的责任在此正面冲突；玩家决定谁先说、谁先听、谁承担公开代价。
7. **含晦阶段化**：保留既有揭言、诱离、过载、战斗、撤退，并补一段“第一次失败后的重整”与一段“战后证词归属”场景。
8. **井口余响**：不论胜负，必须让留守者、病人和证据保管人有可见变化。

### 验收

- 副本首次探索 45 分钟以上，至少四条可独立进入的调查路线。
- 含晦至少三种有效解法可从前置材料、关系或认知中获得，不是五个同质按钮。
- “昼盐账”为人名账的结论须由至少两种不同来源互证。

## 7. 批次 D：人物线与村庄回访网

### 目标

在主线的异常调查外，让杳湾作为一个有具体社会关系的地方存在。此批不新增大谜团，重点让前面选择落到谁吃饭、谁取水、谁能离开、谁敢作证上。

### 内容预算

| 项目 | 目标 |
| --- | ---: |
| 新节点 | 12—16 |
| 新文本 | 24,000—30,000 汉字 |
| 新任务 | 3—4 条人物线 |
| 新遭遇 | 2 个：黑粟试种、撤离名单争执 |
| 新材料/工具 | 4—5 件 |
| 首次游玩增量 | 75—100 分钟 |

### 人物线优先级

| 人物 | 关键场景 | 玩家选择 | 终局/雨后回响 |
| --- | --- | --- | --- |
| 阿禾 | 小满是否进入撤离名单；无名树是否保留 | 救羊、留羊守村、以树名换撤离时间 | 留名者/牧人/失名者三种态度。 |
| 宿沙 | 儿子的名牌、蜡印和船是否公开 | 公开、暂存、伪造通行记录 | 暗渠开放度、盐泽路线与他的信任。 |
| 青芽 | 黑粟、药物与配给公开 | 隔离、试种、焚毁；公开或暗分 | 村中粮荒、水病与夜谷余响。 |
| 砚伯与缄婆 | 谁先听昼盐账，谁先承担责任 | 村民先听、三方抄本、暂封待证 | 诚实碑、清白历书、守井人结局。 |
| 砚童与隗青 | 梦行被公开还是被保护 | 入梦唤醒、暂时隐瞒、以证词换保护 | 清醒者/梦行者；守夜人是否继续守夜。 |

### 回访地点

必须补齐至少 7 个可回访点，使总数达到 12：第七口井、粮仓、染坊、渡口、祠屋、东桑林边缘、旧盐井棚、北滩、盐泽棚屋、撤离岔口、河床浅滩、雨后路标。

每个地点至少有两种状态文本：黑雨中与雨后；关键地点再加入“已准备/未准备”或“证据公开/未公开”条件段。

## 8. 批次 E：第七日谈判、终局差异与雨后余响

### 目标

保留四条主结局的汇合结构，但让结局不是最后一次选项的产物，而是此前人物线、材料、证据和准备状态的总和。

### 内容预算

| 项目 | 目标 |
| --- | ---: |
| 新节点 | 8—10 |
| 新文本 | 18,000—24,000 汉字 |
| 新任务 | 1 条四方临界谈判任务 |
| 新图鉴 | 4 条余响/洞彻层 |
| 首次游玩增量 | 50—70 分钟 |

### 执行内容

1. 在北滩终局会议前增加四方临界谈判：杳湾、盐泽流民、北方使者、羿/三影者。
2. 每一方至少有一个不可回避的具体问题：粮、路、孩子、证词、箭的归属。不得只谈“秩序”“自由”等抽象名词。
3. 将前置状态接入最终会议：撤离名单、公开配给、旧账副本、河运蜡印、梦壳处置、井口准备、含晦结果。
4. 四条结局保持为：交羿、东行、折箭、交北方/交易；各结局新增人物段落与地点段落，而非复制四套长主线。
5. 雨后回访按组合余响呈现：至少 18 个角色/地点条件段，且每段可由玩家明确说出来源选择。

### 验收

- 最终会议至少读取 6 个前置状态。
- 每条结局至少有 3 个独有余响和 2 个共用但文本变化的余响。
- 完成后能明确显示玩家做过的选择、保留的证据和第二卷输入，不把真相简化为单一判词。

## 9. 推荐生产顺序与里程碑

| 里程碑 | 批次 | 完成条件 | 预计累计全探索时长 |
| --- | --- | --- | ---: |
| M1 | A 倒船腹舱 | 12—14 节点、三条解法、宿沙余响 | 4—5 小时 |
| M2 | B 东桑十巢 | 阿禾完整对立、梦壳/东行回响 | 5—6 小时 |
| M3 | C 旧盐井 | 45分钟副本、含晦阶段化、证据链闭合 | 6.5—8 小时 |
| M4 | D 人物与回访 | 六条核心人物线可收束、12个回访点 | 8—9.5 小时 |
| M5 | E 终局与余响 | 四方谈判、18个余响、试玩计时 | 9—11 小时 |

每个里程碑完成后按以下顺序复盘：

1. 从新档走最短主线，记录节点、阅读时间、战斗/调查时间与卡顿点。
2. 从新档完成当前所有副本和人物线，记录漏读节点与无法理解的状态。
3. 检查每个新材料是否至少被获得、显形、使用各一次。
4. 检查每条人物线是否有欲望、秘密、对立、选择、状态回响五项。
5. 运行 JSON/可达性校验、工程测试和静态检查；更新章节备份、清单、日志与实际时长估算。

## 11. 当前不做的事项

- 不新增需要独立数值系统支持的大型生产、经营或随机刷取玩法。
- 不为了字数复制平行主线；高价值分歧采用状态变量汇合。
- 不把配音、逐字动画、等待倒计时或强制反复阅读计入十小时。
- 不修改已发布稳定 ID 或悄然改变 V1.3 基线中的世界观、核心玩法与结局边界。
