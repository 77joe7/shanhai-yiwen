# GAME_DESIGN｜《山海异闻录：天地未定》

## 1. 体验合同

玩家不是来旁观一名普通人的一生，而是借一个普通人的眼睛和双手，第一次进入仍在呼吸、迁徙、争斗和衰亡的远古山海。开局的普通，是为了让玩家亲手获得进入神话的资格；终局的成长，是能与神谈条件、与伙伴共担危险、改变一条河或一段历史，却仍看得见每个具体生命的代价。

首分钟目标：黑雨截断赤水渡路。玩家必须在记历棚、渡口、粮仓中选择一处落脚，立刻知道“我要活过今晚”，并看见更大的世界已经通过盐粮路、北方印信、流民和东向天象压到这里。

体验曲线：**陌生与惊奇 → 探索与掌握 → 结伴与冒险 → 选择与承担 → 世界发展后的共情。**

## 2. 核心动词与循环

| 动词 | 玩家做什么 | 立即反馈 | 后续变化 |
| --- | --- | --- | --- |
| 行游 | 选择路线、时机与进入方式 | 看到地貌、天气、势力、异兽痕迹与风险 | 新地点、捷径、封锁或迁徙路线改变 |
| 察异 | 观察、比对证词、使用材料或知识 | 获得可验证线索，而非万能解释 | 可谈判、可战斗、可安抚或可制作的行动改变 |
| 交涉 | 询问、交换、承诺、拒绝、公开或隐瞒 | 对方改变筹码、态度、计划或公开范围 | 关系、协助者、敌对者、支线方向改变 |
| 应对 | 战斗、守护、安抚、诱导、撤离、封存 | 风险、伤势、异兽反应和环境状态立即变化 | 知识、伙伴、路线、物件和世界状态改变 |
| 结伴 | 与人或可结伴异兽同行、照料、分担、告别 | 同伴给出意见、技能、情绪与自己的行动 | 可用路线、遭遇解法、人物结局和情感关系改变 |

短循环：`看见问题 → 判断它是什么 → 选一种介入方式 → 看见对象反应`。

长循环：`进入新地域 → 建立知识和羁绊 → 用新手段解决更高层的危机 → 世界改变并开启下一地域`。

核心系统只有“山海行旅”：行动既会读写认知，也会读写羁绊。战斗、谈判、宠物/伙伴协作都是它在不同对象上的表现，不另起彼此割裂的系统。

## 3. 世界规则与必要系统

### 玩家可见规则

- 神、异兽、地点和人物都有可观察的行为规律；玩家通过痕迹、证词、材料和失败逐步理解。
- 进入地点会消耗可解释的时间、补给或关系机会；时间推进会让 NPC、势力、异兽和天气主动行动。
- 同一危险可有交战、谈判、安抚、绕行、协作或撤离等不同解法；知识决定哪种做法值得尝试。
- 伙伴不是物品：能否同行取决于信任、照料、领地/族群条件和其自身意愿；可离开、受伤、死亡或拒绝命令。

### 关键状态的读取

| 状态 | 写入 | 世界如何读取 |
| --- | --- | --- |
| 已知规律 | 玩家观察、验证、遭遇成功/失败 | 新对话、战斗弱点、安抚方式、路线提示改变 |
| 承诺与证词 | 答应、公开、隐瞒、交付物件 | 人物主动来找玩家、提出条件、拒绝协助或改变关系 |
| 同行关系 | 共担风险、照料、违背底线、分别 | 伙伴技能、路线、对话、离队/结局改变 |
| 世界余响 | 核心抉择、灾害处理、势力行动 | 聚落、地图、异兽迁徙、神的态度、下一卷入口改变 |

## 4. 成长与三段弧

| 阶段 | 玩家身份 | 新参与手段 | 新空间/局面 | 可见结束标记 |
| --- | --- | --- | --- | --- |
| 初入山海 | 被卷入者 | 求助、观察、基础交涉、撤离 | 村庄、渡口、荒野边缘 | 第一次独立处理一场神异并得到一个明确伙伴或敌人 |
| 行游山海 | 探索者与同行者 | 组合材料知识、带伙伴协作、选择势力、挑战强异兽 | 扶桑、逐鹿、山海秘境、断裂水道 | 玩家能决定一处地点的通行、一个阵营的协作或一头异兽的去留 |
| 改变山海 | 能承担世界后果的人 | 与神谈判/战斗、组织多人行动、决定世界规则的边界 | 不周山、九州河网、昆仑、天地命名现场 | 世界和人物明确回读玩家做过的具体事，而不只给数值结算 |

## 5. 代表性决策：旧盐井

**当前局面**：黑雨下，杳湾缺粮；旧盐井能短暂析出可换粮的昼盐，但过去曾以孩子的睡眠和牲畜为代价。北方使者愿意收走昼盐并恢复粮路；缄婆要封井；季缨要先取出失踪弟弟的证物。

| 玩家行动 | 适用局面 | 即时结果 | 后续回响 |
| --- | --- | --- | --- |
| 先取证再封井 | 玩家已有井下路线与帮手 | 粮食压力不减，证据被保住 | 遗族信任提高；北方更强硬；卷二获得责任线索 |
| 与北方交易，限量取盐 | 村民即将断粮且谈判筹码足 | 获得粮路，井被短暂保留 | 村民暂时得救；缄婆可能决裂；北方掌握介入权 |
| 立即封井并组织撤离 | 玩家已找到替代路线 | 失去眼前资源，减少后续伤害 | 异兽/孩子线更安全；部分村民认为玩家放弃了他们 |

没有永远正确的选项：粮食越紧，交易越合理；北方信用越低、证据越完整，先取证越合理；替代路线越可靠，封井越合理。因果权在玩家的处置，结算权在村民、北方、缄婆、季缨和下一卷的实际反应。

## 6. 空间、关卡与节拍

每个核心空间采用“教会 → 变式 → 组合 → 检验 → 命运回收”。

| 节拍 | 黑雨切片 | 玩家学到什么 |
| --- | --- | --- |
| 教会 | 三处落脚：记历棚、渡口、粮仓 | 人物会提出具体请求，帮助方式会影响关系 |
| 变式 | 北滩尸体与旧井同时传来消息 | 时间和路线迫使玩家不能把所有事一次做完 |
| 组合 | 旧盐井：物证、同伴、北方条件与环境危险叠加 | 知识、关系和路线必须组合使用 |
| 检验 | 选择谁先处理、谁可见证、是否承担短缺 | 选择会转给不同人代价，世界不等待玩家 |
| 命运回收 | 黑雨停后重访杳湾 | 粮仓、渡口、人物态度、异兽与去路依据历史改变 |

空间要求：一眼可见的主目标、一条低风险主路、一条带证据/伙伴机会的高风险路、一处明确地标。环境描写必须提示可行动的信息，不只制造气氛。

## 7. 反馈、失败与重开

- 每次行动先给对象的反应，再给状态摘要；例如异兽退开、伙伴沉默、渡口封绳、北方印信加盖。
- 失败不是“读档唯一答案”：可能失去时间、受伤、错过信任、迫使人物先行动、关闭一条路线，仍保留可理解的后续。
- 关系失败必须说明触碰了什么底线，给玩家改变策略或承担决裂的机会；不以暗骰突然惩罚。
- 可重开到卷/切片初态，保留清楚的行动记录，让玩家能看懂另一条路径改变了谁。

## 8. 叙事附件

### 场景脊柱

每场以人物议程进入：谁想拿到食物、证物、时间、通行权、承诺或沉默；谁用筹码反制；玩家看见什么证据；哪句话或行动让局势翻转；离场时谁必须采取下一步行动。

### 人物与关系

核心人物有当前欲望、恐惧、底线、秘密证据、关系债和主动计划。友情、爱情、合作、决裂、疏远、死亡与传承全部由共同经历和底线冲突触发，不以单一好感条替代。

### 分支与汇流

小选择表达玩家身份或关系策略；大选择处理世界状态。主线可在危机上汇流，但必须根据历史替换人物、路线、物件和可用行动。未选事件不能污染后续历史。

## 9. 语言、文化与交接边界

玩家可见文本使用易读的现代汉语叙事，保留上古神话的物象、称呼和仪式感；一个段落只引入一个新概念。神异先写可见痕迹、再写有限规则、最后写人的选择。交给美术的效果是：山海有尺度、神与异兽有生命和领地、世界变化能在地貌和聚落中看见；交给构建的效果是：上述动词和回响能被真实执行。

## 10. 可执行切片合同

**最大风险**：文字为主的游戏能否让玩家感觉自己正在探索并改变一个活世界，而不是阅读长篇设定。

**原型形态**：20—30 分钟黑雨白盒切片。

| 项目 | 内容 |
| --- | --- |
| 固定初态 | 玩家刚到杳湾；黑雨第 1 日；无同伴；北方使者未到北滩 |
| 输入序列 | 选择落脚点 → 完成一次人物请求 → 前往北滩或旧井 → 选择交涉/调查/撤离 → 重访一处地点 |
| 关键前置 | 路线、人物是否在场、已知证据、承诺、时间 |
| 效果 | 改变一项知识、一项关系、一项地点状态；至少一项在重访被读取 |
| 观察者 | 至少一位 NPC、一个地点和一个未来节点对行动作出不同反应 |
| 预期反馈 | 玩家能说清自己为什么选、谁得到/失去什么、下一次能尝试什么 |
| 重开验证 | 同一初态下走另一条路径，至少出现不同的对象反应、可用行动或重访场景 |

## 11. 验证切片

范围只验证：探索目标是否清楚、人物是否主动、知识是否改变行动、关系是否回响、世界是否发展可见。

非目标：完整七卷正文、数值平衡、全部异兽收集、开放世界美术、正式战斗深度。

若试玩者无法在结束时回答“我做了什么、谁因此改变、我现在能去哪里、下次为什么会选另一种做法”，则先修正场景、反馈或状态读取，不继续增加文本。
