# 《山海异闻录：天地未定》浏览器系统原型

## 当前范围

- 已实现响应式桌面三栏与移动端单栏/底部导航。
- 第一章剧情数据保持为空；`StoryNode` 内容接入位已经保留。
- 系统沙盘覆盖角色创建、角色资源、探索时间/体力消耗、材料认知、山海志、装备、人物关系、世界变量、本地自动/手动存档、导入导出及阅读设置。
- 不包含登录、服务器、广告、支付、云存档或第一卷正式剧情。

## 分层约定

- `app/game/gameData.ts`：可替换的系统演示数据。后续正式内容不应写入组件。
- `app/game/types.ts`：首版状态与存档契约。
- `app/game/storage.ts`：浏览器本地存档实现，含版本与校验。
- `app/game/platform.ts`：浏览器能力适配边界；后续微信小游戏实现同一接口。
- `app/game/GameShell.tsx`：表现与玩家命令编排，不应承载正式剧情事实。

## 第一章内容接入

后续应增加版本化内容包，并以稳定 ID 提供 `StoryNode`、NPC、Item、Encounter 与 CodexEntry。内容节点只声明条件和 Effect，不直接操作 DOM 或 `localStorage`。系统页面中的“未写之章”应由内容包入口替换，现有存档字段与平台适配层保持不变。

## 微信小游戏适配方向

1. 实现 `PlatformAdapter` 的微信版本，替换存储、文件导出、生命周期、震动与后续音频接口。
2. 保持领域状态、内容 ID、Effect 和存档 Envelope 平台无关。
3. 为触摸安全区、横竖屏策略、资源分包、首包体积、音频解锁和后台恢复增加专项测试。
4. 不在当前 Demo 提前接入微信登录、广告或云开发；这些能力应分别通过 Auth/Ad/CloudSave 接口接入。
