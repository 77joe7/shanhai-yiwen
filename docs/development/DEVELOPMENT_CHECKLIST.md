# 开发与发布检查表

本清单是执行入口；详细规则见 `DEVELOPMENT_STANDARD.md`、`WEB_MOBILE_STANDARD.md`、`WECHAT_MINIGAME_READINESS.md` 和根目录 `VERSIONING.md`。

## 开发前

- [ ] 已阅读 `AGENTS.md` 及适用专项规范。
- [ ] 已运行 `git status --short --branch` 并确认当前分支。
- [ ] 已识别并保护用户或其他任务的现有修改。
- [ ] 已确认需求来源、范围、非目标和验收标准。
- [ ] 已确认受影响的平台、模块、配置、存档、资源和文档。
- [ ] 重大架构/依赖/数据决定已有 ADR 或计划补充。
- [ ] 已确定测试范围、目标视口和真机要求。
- [ ] 已确认仓库远程与备份状态；无远程时已记录风险。

## 开发中

- [ ] 核心玩法不直接依赖 DOM、浏览器或微信专有 API。
- [ ] 平台能力通过适配层调用。
- [ ] 没有硬编码屏幕、密钥、环境地址和可配置游戏数值。
- [ ] 数据和存档变更包含版本、校验与迁移考虑。
- [ ] 新依赖完成许可证、体积、安全和微信兼容性检查。
- [ ] 新资源有来源、授权、格式与预算记录。
- [ ] 错误、超时、取消、重复执行和恢复路径已处理。
- [ ] 自动化测试或可复现验收用例与实现同步。

## 提交前

- [ ] 验收标准逐项通过。
- [ ] 已执行适当的测试、静态检查和生产构建。
- [ ] 已检查桌面/移动视口、触控、安全区和生命周期影响。
- [ ] 已检查存档兼容和旧版本数据（如适用）。
- [ ] 已更新文档、Schema、ADR 和 `CHANGELOG.md` 的“未发布”部分。
- [ ] 已运行 `git diff --check`、`git diff --stat` 和 `git status --short`。
- [ ] 差异中没有敏感信息、临时文件、构建产物或无关修改。
- [ ] 提交只包含一个目的，提交信息符合 `类型(范围): 摘要`。
- [ ] 提交后已检查状态；需要异地备份时已推送受控远程。
- [ ] 若未推送，交付信息明确写明“仅有本地提交，远程备份未完成”。

## 发布前

- [ ] 发布范围已冻结，阻断问题已关闭。
- [ ] `VERSION`、`CHANGELOG.md`、构建版本和文档版本一致。
- [ ] 生产构建可从受控提交重复生成。
- [ ] 浏览器支持矩阵与目标真机回归通过。
- [ ] 首屏、帧率、内存、包体和资源预算达到批准值。
- [ ] 启动、核心玩法、音频、前后台、弱网与存档冒烟通过。
- [ ] 依赖、资源授权、安全、隐私和内容合规检查通过。
- [ ] 上一稳定版本及回滚/前向修复方案可用。
- [ ] 已创建带说明的 `vX.Y.Z` 标签并推送远程。
- [ ] 已确认远程可以检出发布提交和标签，必要的大文件可恢复。

## 微信小游戏发布追加项

- [ ] 已核对发布时最新的微信官方文档和审核政策。
- [ ] 开发者工具、体验版、iOS 与 Android 微信真机均已验证。
- [ ] 主包、分包、远程资源、缓存和更新流程通过。
- [ ] 所有启用的平台能力覆盖授权拒绝、取消、超时与降级。
- [ ] 隐私声明与实际数据收集、SDK 行为完全一致。
- [ ] Web 核心玩法回归通过，没有平台分支造成行为漂移。

## 定期备份与恢复演练（建议每月及重大发布前执行）

- [ ] 默认分支和当前发布分支均已推送受控远程。
- [ ] 所有发布标签已推送，远程保护规则有效。
- [ ] 从空目录重新克隆仓库并检出最近发布标签成功。
- [ ] Git LFS 或外部资产存储中的必需文件可以拉取。
- [ ] 依赖安装、基础构建和关键文档打开验证成功。
- [ ] 记录演练日期、执行人、结果、缺失项和整改期限。
