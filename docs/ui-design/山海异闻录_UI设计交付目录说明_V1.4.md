# 《山海异闻录：天地未定》UI 设计交付目录说明

版本：V1.4
状态：受控目录规范
适用目录：`docs/ui-design/`

## 目录用途

本目录保存可追溯的 UI 设计输入、任务书、视觉系统规范、界面说明书和已授权参考原包。所有文本采用 UTF-8；同步盘、压缩包、编辑器历史和未提交工作区均不能替代 Git 版本记录与受控远程备份。

## 命名与版本

- 受控文本格式：`山海异闻录_文档类型_范围或主题_V主版本.次版本.扩展名`。
- 更新已发布文档时必须使用新文件名；不得覆盖或删除历史版本。
- UI 文档版本与正文首页一致；外部输入使用“源V”标识，不冒充项目发布版本。
- 文本规范不应使用“最终版”“新版”“副本”或日期替代版本号。

## 交付与变更要求

1. 视觉实现必须引用 V1.4 的页面和组件规则；基础色值、字阶和间距仍与 V1.3 一致，除非随后发布新的令牌表。
2. 每项实质变更同步登记 `CHANGELOG.md` 的“未发布”部分，执行 UTF-8 检查、`git diff --check`、版本/文件名一致性检查和范围核对。
3. 未经授权的图像、字体、图标、角色、地图与素材不得进入构建；所有正式资产应登记来源、许可证、版本、用途和降级方案。
4. 提交后应推送受控远程形成异地备份；若未推送，交付必须明确“仅有本地提交，远程备份未完成”。
