《山海异闻录：天地未定》UI设计交付目录说明
版本：V1.3
状态：受控目录规范
适用目录：docs/ui-design/

======================================================================
一、目录用途
======================================================================

本目录只保存可追溯的 UI 设计输入、任务书、界面说明书与已授权参考原包。
所有文件必须以 UTF-8 编码保存，并通过 Git 受控提交；本地同步盘、压缩包和未提交工作区均不能替代远程 Git 备份。

======================================================================
二、强制命名规则
======================================================================

文本规范命名格式：
《项目名》_《文档类型》_《范围或主题》_V主版本.次版本.txt

参考原包命名格式：
《项目名》_《来源或用途》_《主题》_源V主版本.次版本.zip

命名约束：
（1）项目名固定为“山海异闻录”。
（2）文档类型使用明确业务语义，例如“UI界面设计详细任务书”“UI界面说明书”“UI设计交付目录说明”。
（3）范围或主题应能说明载体、界面范围或来源，例如“竖屏750x1334”“Stitch参考包基线”“移动MUD界面”。
（4）受控文本的版本号必须与文件正文第一屏显示版本、当前项目受控版本完全一致，使用 V主版本.次版本；不使用“最终版”“新版”“修改版”“副本”“（1）”或日期替代版本号。外部参考原包使用“源V主版本.次版本”标记其来源版本，不冒充项目发布版本。
（5）尺寸使用半角字母 x，例如“750x1334”；不在文件名中使用空格、括号、无语义序号或不稳定的下载名称。
（6）同一受控文本更新时与当前项目版本同步并改用新文件名；已发布版本通过 Git 提交与标签恢复，不覆盖或删除历史版本。

======================================================================
三、当前受控文件清单
======================================================================

（1）山海异闻录_UI界面设计详细任务书_竖屏750x1334_V1.3.txt
    用途：Stitch 生成、UI/UX 设计、响应式原型与工程实现的主任务书。

（2）山海异闻录_UI界面说明书_Stitch参考包基线_V1.3.txt
    用途：将已授权的 Stitch 移动 MUD 参考包转换为可执行的视觉、组件、层级与交互规范。

（3）山海异闻录_Stitch参考原包_移动MUD界面_源V1.0.zip
    用途：参考输入原包；只可用于本项目 UI 视觉和结构参照，不得作为发布构建资源直接引用。

======================================================================
四、备份与交付要求
======================================================================

（1）每次实质修改同时更新 CHANGELOG.md 的“未发布”部分，并以单一目的 Git 提交保存。
（2）提交后必须推送至受控远程仓库，才算异地 Git 备份完成；未配置远程时必须记录“仅有本地提交，远程备份未完成”。
（3）参考原包需要保留来源、用途、版本与授权信息；未经核验的外部资源不得进入发布包。
（4）交付前执行 UTF-8 编码检查、git diff --check、文件名与正文版本一致性检查，以及 Git 工作区范围核对。
