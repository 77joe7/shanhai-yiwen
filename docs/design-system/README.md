## 强制使用规则

1. 组件样式引用 `--ds-*`，不得引用 `globals.css` 的旧变量。
2. 页面规范只引用 `tokens.ts` 中实际存在的变量名，不在规范卡复制 HEX。
3. 每个页面规范必须覆盖 10 个维度：布局、配色、字体、组件、间距、交互、无障碍、动效、图像图标、响应式。
4. 派生色必须在 `specRef` 中标明“派生”，并附文字/符号/结构，不得唯色。
5. 演示插画的颜色由当前令牌动态注入；正式美术资源另走资源清单、授权、版本和降级流程。
6. 组件调用浏览器能力必须经过 `DsPlatform`；业务页面不得复制一套组件或平台判断。
7. 修改后至少运行设计系统专项测试、定向 ESLint、生产构建，并检查所有 `--ds-*` 引用均有定义。
8. `--ds-f-seal` 是小篆装饰栈，只能用于游戏名、页面大标题和底部主导航标签；当前开发设备优先使用已安装的「峄山碑篆体」，正文、数值、状态、错误与唯一操作识别继续使用高可读字体。它不打包未授权字体：设备无小篆时必须无感回退至宋体，布局与触控面积不变。
9. 游戏功能页可在 `GameShell` 的 `.mythic-shell` 根上调用 `buildTokenStyle()` 并消费 `--ds-*`；仅允许替换展示层令牌和交互状态样式，剧情、存档、数值与平台访问仍留在既有游戏模块与适配层。
