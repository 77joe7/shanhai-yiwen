# 第三幕《倒河》至第五幕《十日之兆》互动剧情更新框架

> 配套第一、二幕分支实现：`app/game/branching/acts.ts`（19 节点，总分结构，三后果轴：羿箭 / 迟日 / 含晦）。
> 本框架延续同一规格：**每节点选项 ≤3 且带 `no` 编号**、`visibleWhen` 谓词触发、`effects` 写 flag/世界变量、**总分结构**（主干推进 → 关键节点持续分支，不再汇流回同一结局）。
> 世界观 / 人物 / 时间线 / 风格延续卷一母稿；副本、人物线、结局均以既有受控内容为基线，不新增未批准的设定。

---

## 〇、总体设计原则（五条要求的落实）

| 要求 | 落实方式 |
|---|---|
| 1. 选项机制 ≤3 且差异化 | 每个决策节点 `choices` ≤3；选项在**目标 / 代价 / 立场**三个维度上互斥，绝不同质（例如"调查方向"节点必有 3 个截然不同的地点/人物走向） |
| 2. 总分结构 | 每幕设「主干推进节点」+「持续分支线」。**第三幕三分叉、第四幕二分叉、第五幕六分叉**，各自有独立中间节点与转折，最终**6 个卷终结局互不汇流**（延续 A2-END-* 的总分传统） |
| 3. 分支多样性 ≥3 走向、关键节点 ≥6 结局 | 全卷 3 大主干走向（求真·调查线 / 守护·人际线 / 借势·阵营线）；**第五幕最终抉择一次性裂出 6 个卷终结局**（含 2 个隐藏结局，需第一二幕特定积累解锁） |
| 4. 第二卷伏笔与接轨 | 每幕埋设 2-3 条第二卷线索（隐藏角色、未解之谜、暗示事件），全部落为可枚举的世界变量（`sky.suns.count` / `corpse.fate` / `unique.red_arrow.owner` 等），与 `world-state.json` 的 V02 消费者对齐 |
| 5. 叙事一致性 | 复用既有 11 NPC、五幕时间线（黑雨七日 + 倒河 + 无日之夜 + 十日之兆）、副本与人物线；文风延续卷一（魔幻现实、东方史诗、青春群像、悬疑成长，参考百年孤独的循环宿命 / 沧月《镜》的苍凉史诗 / 江南的群像热血） |

## 一、第三幕《倒河》　叙事问题：是谁，让黑雨流进了杳湾的过去？

### 1.1 主干与三分叉

```
A3-ENTRY（三卷终桥接，见 1.2）
  └─ A3-HUB「赤水倒流」（主干推进：河床 / 东桑 / 村中 三去处）
       ├─ [线A·求真] A3-RIVER-1「河床下的路」→ A3-RIVER-2「舱门里先出来的是名字」→ 副本 DB-V01-01 倒船腹舱
       ├─ [线B·守护] A3-GROVE-1「一夜长成的桑林」→ A3-GROVE-2「十巢不在同一棵树上」→ 副本 DB-V01-02 东桑十巢
       └─ [线C·借势] A3-VILLAGE-1「替尸体做梦的人」→ A3-VILLAGE-2「蜡封下是第十夜」→ A3-VILLAGE-3「谁替孩子醒来」
  └─ A3-MERGE「第四日：井绳没有断」（三线可回访交汇点，不强求全走完）
       └─ A3-END「旧盐井」（第四幕入口）
```

## 三、第五幕《十日之兆》　叙事问题：你的选择，改变了谁的生活？

### 3.1 主干与六分叉（全卷总分收束点）

```
A5-ENTRY（承接 A4-END）
  └─ A5-HUB「第七日之前」（四方陈述 / 村约 / 回访可回）
       └─ A5-FINAL「黑雨停了」（最终抉择 → 六卷终，互不汇流）
            ├─ E1 交羿    —— ending.yi_arrow_marks_shared / unique.red_arrow.owner
            ├─ E2 东行    —— ending.east_water_route_open / corpse.fate=eastbound
            ├─ E3 折箭    —— ending.chiri_name_open（迟日线开启）
            ├─ E4 北方交易 —— ending.north_debt_marked / faction.north.has_red_arrow
            ├─ E5 隐藏·封井永守 —— 需 nonNegotiablesWritten + 缄婆线完整（village.seventh_well_isolated）
            └─ E6 隐藏·三影者自由 —— 需 chiri_name_open 且 拒绝交托三方（corpse.fate=released）
```

### 3.2 最终抉择节点 A5-FINAL「黑雨停了」（≤3 选项，分两步裂出 6 结局）

**第一步（3 选项）**
| no | 选项 | 走向 |
|---|---|---|
| 1 | 把箭与尸体交给羿（交予英雄） | → 进入 E1 / E6 分支 |
| 2 | 让尸体带箭继续向东（放行道路） | → 进入 E2 / E6 分支 |
| 3 | 折断箭杆，把箭镞留给人间（留权于民） | → 进入 E3 / E5 分支 |

**第二步（每步 2 个 `visibleWhen` 子选项，解锁隐藏结局）**
- 若 `doubtYi=true` 且 `truthPublic=true` → 出现「不交给任何人，让三影者自己决定去留」→ **E6 三影者自由**
- 若 `nonNegotiablesWritten=true` 且 `village.memories_restored=true` → 出现「封井永守，杳湾自己扛下第十日」→ **E5 封井永守**
- 其余情况在对应轴内二选一（交羿/共证 vs 交羿/质问；东行/直行 vs 东行/留灯；折箭/留镞 vs 折箭/交由村民共管）

### 3.3 六结局清单

| 结局 | 名称 | 触发 | 写入世界变量 | 第二卷接口 |
|---|---|---|---|---|
| E1 | 把未来交给射手 | 交羿（默认 / 共证 / 质问三态） | `ending.yi_arrow_marks_shared=true`、`unique.red_arrow.owner=yi` | 羿线问责记录 |
| E2 | 东行的人没有回头 | 尸体带箭东行 | `ending.east_water_route_open=true`、`corpse.fate=eastbound` | 东行水路入口 |
| E3 | 迟日先学会吃饭 | 折箭留镞 | `ending.chiri_name_open=true` | 迟日身份线输入 |
| E4 | 一村人的价钱 | 季狸接管交易 | `ending.north_debt_marked=true`、`faction.north.has_red_arrow=yes` | 北方债务线输入 |
| E5 | 井口不是公堂（隐藏） | 封井永守 | `village.seventh_well_isolated=true`、`village.day_salt_truth_public=true` | 井病自守·第二卷盐线 |
| E6 | 三影者自己决定（隐藏） | 拒绝交托三方 | `corpse.fate=released`、`ending.chiri_name_open`（可选否） | 三影者自由线·卷二核心输入 |

> 六结局 = 4 常规（延续母稿 N023-A/B/C/D 四条结局）+ 2 隐藏（需前面积累解锁），**完全覆盖"关键节点 ≥6 种结局"要求**；三条主干走向（求真 / 守护 / 借势）由第一至四幕的选择持续累积，最终在六卷终分别落地。
