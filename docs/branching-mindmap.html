【世界背景 · 黑雨与杳湾（未单列节点的设定，先读此处）】
「黑雨」不像是水，更像一整片天在往下塌；雨里混着不属于人间的纹路（后文称「黑雨纹路」）。故事发生在滨海村落 杳湾村，村中有三处长明灯火——记历棚（砚伯）、渡口（宿沙）、粮仓（青芽）——它们既是避雨的去处，也是玩家最初结下人情的三个起点。村子深处有一口 会「哭」的老井：不是水响，是有人在水底下说话；井底结着「昼盐」浮尘，墙里嵌着半面残镜（照不出人，只照出一直在下的雨）。村外 北滩 常漂来异象——本幕核心是一具肩带赤金箭痕的 「三影者」浮尸，与三道在雨幕里分立、似在等谁先动的影子。这些设定贯穿两幕，是分支抉择的底层语境。
第一幕《雨至》 玩家抵达杳湾，三条路线结人情 → 汇于「井哭」异象 → 三去向 → 幕终承诺身份

【幕间脉络 · 第一幕如何「交叉影响」第二幕（未单列节点的承接逻辑）】
第一幕里你结下的人情（helpChronicle / helpFerry / helpGranary…）与偷得的秘密（snoop 偷看宿沙的货、knowHanhui 取过昼盐、seekOrigin 追问黑雨、knowWellHistory 抄过雨谱）会被第二幕读取：
① role 决定第二幕从哪个入口开局；② snoop 让第二幕渡口线多出「又去瞟舱里那卷」专属选项；③ knowHanhui 让第二幕独行线多出「先去井边取昼盐」选项、并让含晦线读出盐纹一角；④ seekOrigin 让第二幕羿箭线追加「箭痕缠黑雨纹路」细节；⑤ knowWellHistory 让井底不再有茫然描写。
这些 visibleWhen 只是「同一节点 ≤3 选项里哪些出现」的门槛，绝不突破每节点 3 选项的上限。

【第二幕前情脉络 · 三种身份 = 三种开场立场（未单列节点的设定）】
第二幕不再重复「落脚去处」，而是承接第一幕的 role：记历人从砚伯的棚开场，天然带着「该不该把井与尸写进雨谱」的抉择；渡工同伴随宿沙出船，重心在水上行动与那卷始终不许看的货物；独行者谁也不靠，直接追昨夜的三道影子。三条开场都指向同一桩异象——北滩浮尸，但玩家手里已握着不同的筹码（人情、昼盐、黑雨线索）。

【北滩异象脉络 · 浮尸、三影与含晦（未单列节点的设定）】
北滩浮尸是一具 「三影者」——肩头那道 赤金箭痕 来自 羿（本幕现身的人物），但羿声称箭不是他射出的，而是「有人把我的箭，钉进了一具早该安息的身子」，指向一桩被栽赃的往事。三道影子 是被封之名/被掩之人的化身，中间那道似要认一个名字（后文揭为「迟日」），另两道却把它往回拖。「含晦」 则是老井深处封着的一句话——缄婆说「盐里封着一句话，揭了，就有人要来讨债」，与北方来的使者、昼盐同源，是另一条被掩埋的因果线。三后果轴正对应玩家对这三桩「真相」的不同姿态。

【三后果轴脉络 · 三种「真相姿态」对应三种卷终（未单列节点的结果导向）】
玩家在「北滩有尸」选了哪条轴，就进入哪一种对「真相」的处理方式：
· 羿箭轴＝追查「谁把羿的箭栽进尸体」——把箭痕拓下共管 / 交还羿独自追 / 质问羿，最终收敛为 箭痕未冷；
· 迟日轴＝给被封之影「正名」——唤出「迟日」/ 按住沉回 / 只记方位，最终收敛为 迟日有名；
· 含晦轴＝处置「井里被封的那句话」——揭罐 / 交使者 / 原样封回，最终收敛为 盐封启闭。
三者互不汇流，各自独立成卷终，因此第一、二幕整体呈「总分」而非「总分总」。
